# Правила работы в проекте «Снежный привет» (Деда Мраз)

Этот файл собирает все правила, которых Claude должен придерживаться в этом проекте.
Источники: сообщения владельца (General), заметки проекта, `scenes_v3/VIDEO_PLAN_V3.md`,
`greeting_service/README.md`, `service/DEPLOY.md`.

## 1. Главные правила общения (от владельца, 27.11.2026)

1. **Ничего не удалять без 2–3 разрешений.** Файлы, ветки, заказы, видео, голоса, узлы графа — только после того, как владелец 2–3 раза явно подтвердил удаление. Вместо удаления лучше переименовать или переложить в папку `_to_delete/`.
2. **Говорить по-русски и простыми словами.** Без жаргона; если термин нужен, объяснить его.
3. **Перед изменением сказать, что будешь делать.** Коротко: какой файл / что меняется / зачем.
4. **В конце: что сделал и где результат.** Ссылка на файл, PR, адрес или папку.
5. **Не уверен — спроси.** Если не ясно, что имел в виду владелец, или есть сомнение — сначала задать вопрос, а не делать наугад.

## 2. Язык продукта

- Продукт на **сербском** (экавица, Сербия), Деда Мраз. Сценарий, имена, озвучка, текст на бумаге — сербские, **латиница**.
- Общение с владельцем — по-русски; рядом с сербским текстом давать перевод.
- Не делать украинские/русские списки имён для продукта.
- Текст нейтральный по полу; в голосе — звательный падеж (вокатив), на бумаге — именительный.

## 3. Деньги и платные генерации

- **Никаких платных генераций без явного «да» владельца** (Veo, Seedream, HeyGen, ElevenLabs). Владелец уже потерял много кредитов (сцена 1а — 7 664 кредита впустую, нарезки Veo — 60k+).
- Сначала картинка, потом видео: 4 варианта стартового кадра → владелец выбирает → только потом видео с этим кадром.
- Никогда не запускать 1080p «вслепую»: сначала согласованы кадр и промпт.
- Скрипты озвучки по умолчанию только считают стоимость; тратят только с флагом `--yes`.

## 4. Видео и шаблон

- **Мастер-видео — база всего, его качество не портить** (слова владельца, 27.11). Не пережимать и не перекодировать мастер без нужды; любые облегчённые версии делать отдельными файлами, оригинал оставлять как есть.
- Сервис устроен как **«шаблон + переменные»**: базовое видео делается один раз, в каждом заказе меняются только имя (голос + надпись в книге) и фото (в рамке). Нейросетью видео под заказ **не генерируется**.
- Имя произносится только там, где лицо Деда не видно (или в отдельном lip-sync кадре). Без хобби.
- Базовое видео монтирует сам владелец в VN (Mac). Мастер: `master.mp4` без имени, зона фото — чистый чёрный.
- Клип не должен заканчиваться с открытым ртом / на полуслове.
- Музыка — один непрерывный трек под всем роликом, без скачков; под голосом тише, переходы громкости плавные 0,6–0,8 с.
- Без текста в генерации: имя на книге и портрете накладываем сами.
- Промпты писать максимально подробно (стиль, персонаж из «библии», место, действие по секундам, камера, свет, настроение, запреты). В конце каждого промпта — общие запреты:
  `No text, no captions, no logos, no watermarks, no extra people, no distorted hands or faces, no modern objects, not cartoon, no sudden cuts, no camera shake.`
- Ролик с замечаниями (лицо не найдено, незнакомое имя и т.п.) никогда не уходит клиенту сам.

## 5. Голос (ElevenLabs)

- Голос «ded mrez». Реплики Деда для ребёнка — нежные, тёплые.
- Длинные реплики делить на части, чтобы дубль не обрезался.
- Не писать многоточие «…» в тексте для Eleven v4 — он обрезает дубль. Использовать запятые или делить фразу.
- Аудио, выгруженное из VN, может оказаться видео (MP4) с расширением .mp3 — проверять командой `file` и вынимать звук через ffmpeg.

## 6. Файлы владельца и безопасность

- Не переименовывать и не перемещать файлы, которые положил сам владелец, если он не попросил про конкретный файл.
- Ключи (ElevenLabs, Resend и др.) — только в переменных окружения / `.env` на сервере. Не читать и не печатать файл с ключами (`Documents/site/"api key"/`). Владелец сам вставляет ключи.
- На сервер заходить только по SSH-ключу, никогда паролем.

## 7. Граф Graphify

- После каждого результата или решения добавлять заметку в граф `/mnt/project-files/graph.html`.
- Инструмент: `greeting_service/tools/graph_note.py notes.json` (сам делает копию `graph.html.bak`).
- Граф — общая карта всей работы владельца по всем потокам.

## 8. Репозиторий и сервер

- Сайт: корень репозитория (`index.html`, `app.js`, `style.css`, `privacy.html`). Сервис заказов: `service/` (см. `service/DEPLOY.md`).
- Изменения — через отдельную ветку и PR; в `main` напрямую не писать.
- Обновление сервера: `cd ~/site && git pull && cd service && docker compose up -d --build`. Деплой на сервер — только после «да» владельца.
